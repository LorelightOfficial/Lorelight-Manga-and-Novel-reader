# Contributing to Lorelight

Thanks for your interest in the project. Application source is maintained in a private repository, so this repository does not accept source code pull requests. There are still several useful ways to contribute here.

## Ground rules

- Be respectful — see the [Code of Conduct](CODE_OF_CONDUCT.md).
- Never post keystores, passwords, tokens, or `.env` contents anywhere in an issue.
- Requests to bundle a specific piracy source are out of scope — Lorelight ships no content of its own.

## Reporting a bug

Use the bug report issue form. A useful report includes:

- The app version and build number (Settings → About)
- Android version, device model, and which APK variant you installed
- Exact steps to reproduce, and what you expected instead
- The diagnostics log from Settings, with anything personal removed, if a crash or stall is involved

## Requesting a feature

Use the feature request issue form. Describe the reading situation that's awkward today before proposing a fix — it helps prioritise real friction over preference.

## Translations

If you spot a wrong or missing translation, open an issue naming the language and the exact string, with the correct wording. Translation files aren't hosted in this repository, but reports are triaged against them directly.

## Documentation fixes

Typos or unclear wording in this repository's own files (README, this file, the security policy) can be fixed directly with a pull request.
